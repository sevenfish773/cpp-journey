# notes 费曼式笔记目录

## 为什么要写这个

你的核心问题是**"学过但遗忘"**。对抗遗忘最有效的方法不是重读笔记，而是：

1. **用自己的话把它讲出来**（费曼技巧）
2. **一周后删掉代码重写一遍**

这个目录就是存放这些"自己讲的话"的地方。**每条控制在一屏以内，越短越好。**

## 写法要求

- 假设读者是"一个月后的我自己"，他能看懂吗？
- 不要复制书本原话，用你自己的理解写
- 每条笔记必须有**一个具体例子或一段代码**
- 能画图的就画图（可以用 ASCII 图）
