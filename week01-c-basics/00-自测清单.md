## 四个函数的验收要点

### 1. `my_strlen`
- [ ] 空字符串返回 `0`
- [ ] `"hello"` 返回 `5`
- [ ] **不把结尾的 `'\0'` 算进去**（这是最常见的错）
- [ ] `NULL` 返回 `0`（本练习约定）

### 2. `my_strcpy`
- [ ] 返回 `dest`（**不是** `dest` 的末尾！这是高频 bug）
- [ ] 拷贝内容完全一致
- [ ] 拷贝空字符串时，`dest[0]` 必须是 `'\0'`
- [ ] **不能**用 `strcpy` / `memcpy`

### 3. `my_strcat`
- [ ] 返回 `dest`
- [ ] 先找到 `dest` 的 `'\0'` 位置，从那里开始拷
- [ ] 追加空字符串不改变原内容
- [ ] 想清楚：调用者为什么必须保证 `dest` 空间足够？

### 4. `my_strdup` ★ 本周重点
- [ ] `src` 为 `NULL` → 返回 `NULL`
- [ ] 分配字节数 = `strlen(src) + 1`（**+1 是给 `'\0'` 的**，漏了会出大问题）
- [ ] `malloc` 返回 `NULL` 时也要返回 `NULL`（内存不足的情况）
- [ ] 空字符串 `""` 也要分配 1 字节，不能返回 `NULL`
- [ ] 返回值是**新内存**，不是原指针
- [ ] 写完之后能回答：**谁负责 `free`？忘了 `free` 会怎样？**
