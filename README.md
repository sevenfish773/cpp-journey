## 每日流程（雷打不动）

```powershell
# 1. 写代码（哪怕只有 20 行）
# 2. 编译 + 跑测试
# 3. 提交
git add .
git commit -m "week01: 手写 my_strdup，处理了 src 为 nullptr 的情况"
git push
```

**提交信息要写清"做了什么"，不写 "update" / "修改"。** 面试官真的会翻提交历史。

## 我的规则

1. 每个知识点必须先自己手写一遍，**之后**才允许用 AI 对照
2. 每周日把本周代码**删掉重写一遍**，不看原代码
3. 同一时间只允许 1 本书 + 1 门课 + 1 个项目
4. 报错先自己读、自己调，查不到再问
